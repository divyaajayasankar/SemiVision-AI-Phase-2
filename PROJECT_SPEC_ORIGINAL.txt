# 4. FROZEN TWO-PHASE RESEARCH ARCHITECTURE

There are exactly **two research phases**.

Do not replace this methodology.

# PHASE 1 — 2-D CNN / CONVOLUTIONAL AUTOENCODER BASELINE

Pipeline:

```text
Carinthia-S SEM Images
        ↓
Reference Images Only
        ↓
Image Preprocessing
        ↓
2-D Convolutional Autoencoder
        ↓
Image Reconstruction
        ↓
Global Reconstruction Error
        ↓
Reference/Calibration Threshold
        ↓
REFERENCE / ANOMALY
        ↓
Freeze Phase-1 Model + Policy
```

Phase 1 must be **reference-only/unsupervised anomaly detection**.

Do not implement Phase 1 as a supervised six-class classifier.

The model learns characteristics of normal/reference semiconductor structures such as:

```text
texture
shape
edges
grayscale intensity distribution
surface morphology
repeated semiconductor patterns
spatial structure
```

For image `x` and reconstruction `x_hat`:

```text
MSE(x, x_hat)
=
(1/N) Σ (x_i - x_hat_i)^2
```

Interpretation:

```text
Low reconstruction error
→ similar to learned reference structure

High reconstruction error
→ potentially anomalous semiconductor structure
```

## Phase-1 neural network

Use a lightweight **2-D Convolutional Autoencoder**.

Input:

```text
grayscale SEM image
1 channel
```

Recommended implementation if no valid model already exists:

```text
Encoder:
Conv2D
→ ReLU
→ Conv2D
→ ReLU
→ Conv2D
→ ReLU
→ latent representation

Decoder:
ConvTranspose2D / Upsampling
→ ReLU
→ ConvTranspose2D
→ ReLU
→ output reconstruction
```

Use:

```text
Loss      : MSE reconstruction loss
Optimizer : Adam
Seed      : 42
```

Use early stopping based only on reference-validation reconstruction loss.

Save the best checkpoint.

If a valid Phase-1 model already exists:

```text
models/convae_best.pt
```

or another valid equivalent checkpoint:

**reuse it instead of unnecessarily retraining it.**

# 6. PHASE-2 COMPONENT A — ERROR MAP

Calculate:

```text
E_i = (x_i - x_hat_i)^2
```

Generate a reconstruction-error map for each image.

This map will be used for:

```text
localized anomaly evidence
heatmaps
predicted masks
defect localization
```

A documented fixed smoothing filter may be used if required.

---

# 7. PHASE-2 COMPONENT B — GLOBAL SCORE

Calculate global reconstruction error using:

```text
S_global = mean(E)
```

---

# 8. PHASE-2 COMPONENT C — LOCAL TOP-K SCORE

Flatten the error map.

Take only the largest reconstruction errors.

Evaluate:

```text
top-k candidates:

0.001
0.005
0.01
0.02
0.05
```

For each candidate:

```text
S_local
=
mean(top k fraction of reconstruction errors)
```

Select the top-k value using **VALIDATION DATA ONLY**.

Never use final test data for top-k selection.

---

# 9. ROBUST NORMALIZATION

Normalize global and local scores before fusion.

Fit normalization statistics only using allowed:

```text
TRAIN
VALIDATION
CALIBRATION
```

reference data.

Possible robust approaches:

```text
median + MAD

or

median + IQR
```

Do not fit normalization parameters using TEST data.

---

# 10. GLOBAL + LOCAL FUSION

Implement:

```text
S_fused
=
Z_global
+
lambda × Z_local
```

Evaluate a validation-only grid for `lambda`.

Select lambda from VALIDATION data.

Do not calculate candidate test performance while choosing lambda.

---

# 11. CONFORMAL RISK CALIBRATION

Use reference-only calibration scores.

For calibration anomaly scores:

```text
α1, α2, ..., αn
```

and a new sample score:

```text
αnew
```

calculate:

```text
p =
[1 + number of calibration scores >= αnew]
/
[n + 1]
```

Interpretation:

```text
Large p-value
→ image resembles reference distribution

Small p-value
→ image is unusual relative to reference distribution
```

Calibration must use reference samples only.

TEST samples must never be included in conformal calibration.

---

# 12. COST-AWARE DECISION POLICY

Missing a real semiconductor defect is more serious than incorrectly flagging a good sample.

Use default manufacturing costs:

```text
False Negative cost = 10
False Positive cost = 1
```

Calculate:

```text
Total Cost
=
10 × FN
+
1 × FP
```

Evaluate candidate alpha/threshold values using only a dedicated policy-validation set.

Select:

```text
alpha*
```

that gives the selected lowest validation cost according to the documented policy.

The test set must not influence alpha selection.
